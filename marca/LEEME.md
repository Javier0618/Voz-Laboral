# Marca TuVozLaboral

Archivos del logo para redes, documentos y prensa. Se generan con `node scripts/og/generar-logo.cjs` a partir del mismo diseño de la web: fuente Instrument Sans, azul tinta `#0F2440` y verde `#2BB3A5`.

| Archivo | Uso |
|---|---|
| `logo-fondo-oscuro.png` | Logo horizontal sobre azul tinta (2400 × 800). Versión principal. |
| `logo-fondo-claro.png` | Logo horizontal sobre blanco (2400 × 800). |
| `logo-transparente-para-fondo-oscuro.png` | Sin fondo, para poner sobre colores oscuros. |
| `logo-transparente-para-fondo-claro.png` | Sin fondo, para poner sobre colores claros. |
| `perfil-redes-1080.png` | Foto de perfil (Instagram, Facebook, TikTok, WhatsApp). Es el icono, con margen para que no se corte en el círculo. |
| `publicacion-cuadrada-1080.png` | Publicación cuadrada con logo y lema. |
| `portada-redes-1500x500.png` | Portada o banner (X, LinkedIn, Facebook). |
| `icono-512.png` | Icono cuadrado pequeño. |

No cambies los colores ni deformes el logo. Deja aire alrededor de, al menos, la altura de la «t».
